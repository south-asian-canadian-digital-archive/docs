## How to read these pages

- **Dates matter.** Numbers and states are dated. If a page and the running system
  disagree, the system wins. Fix the page in a pull request.
- Every page is also available as Markdown (append `.md`), each area as its own
  `llms.txt` set, and the whole site as [`llms-full.txt`](/docs/llms-full.txt). Agents can
  load the [docs skill](/docs/about/ai-tools/#agent-skill). See
  [AI tools](/docs/about/ai-tools/).
