## About

The **South Asian Canadian Legacy Project (SACLP)** site. SACLP is a Province of British
Columbia–funded SASI project (a $1.14 million contribution) whose outputs include the
[Union Zindabad!](/docs/islandora/exhibits/union-zindabad/) exhibit. The site lives on a
subdomain of southasiancanadianheritage.ca.
