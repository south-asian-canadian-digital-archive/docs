# Docs site

Astro + Starlight, for GitHub Pages at `south-asian-canadian-digital-archive.github.io/docs`. Run `bun install`, then `bun run dev` or `bun run build`.

Only `src/content/docs` is published. The Markdown at the repo root is internal and must stay out of the build.

Site code derives from qrate's site, which is AGPL-3.0: see `LICENSE`.
